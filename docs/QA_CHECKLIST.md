# چک‌لیست امنیت، کنترل کیفیت و ارزیابی داخلی ۱۰۰ امتیازی

## چک‌لیست امنیت
- [x] نگهداری کلیدهای API منحصراً در `.env` سرور (عدم وجود در فرانت‌اند یا `localStorage`)
- [x] احراز هویت و امضای نشست با `scrypt` + کوکی `HttpOnly`
- [x] بررسی Magic Bytes، پسوند، MIME و سقف ۲۰MB برای فایل‌ها
- [x] محافظت از Path Traversal (`safeResolveWithin`)
- [x] تفکیک پوشه `storage/` از فایل‌های عمومی وب
- [x] جداسازی متن اسناد با برچسب `UNTRUSTED_DOCUMENT_TEXT` در پرامپت AI
- [x] Rate Limiting در مسیرهای احراز هویت، بارگذاری و AI
- [x] جلوگیری از XSS با `escapeHtml` در فرانت‌اند و خروجی HTML کاتالوگ
- [x] حذف اسرار از لاگ فعالیت‌ها و خطاها (`redactSecrets`)
